# Dashboard Mockups

Below are the dashboard designs for the BI component of the Stolen Vehicle Recovery & Alert System.

## 1. Executive Summary Dashboard
**Purpose:** High-level overview for management.

### Components:
- **KPI Cards**
  - Total Alerts Today
  - Alerts this Week
  - % Alerts Resolved
  - Avg. Response Time
- **Trend Line Chart**
  - Alerts per day (last 30 days)
- **Bar Chart**
  - Alerts by vehicle category (optional)
- **Pie Chart**
  - Resolved vs Unresolved alerts

## 2. Audit & Compliance Dashboard
**Purpose:** Track trigger behavior, denied DMLs, and auditing.

### Components:
- **KPI Cards**
  - Denied Operations Today
  - Total Audit Entries
  - % of Denials vs Allowed DML
- **Bar Chart**
  - Denials by Reason (weekdays, holidays, duplicates)
- **Table**
  - Latest 20 Audit Entries (timestamp, user, action_type)
- **Heatmap**
  - Denials by day of week

## 3. Performance Dashboard
**Purpose:** Monitor system responsiveness and operational efficiency.

### Components:
- **KPI Cards**
  - Average Response Time
  - Number of Active Alerts
  - Vehicles with Multiple Alerts
- **Line Graph**
  - Response time trend (last 30 days)
- **Bar Chart**
  - Alerts per vehicle
- **Table**
  - Vehicles with most alerts
